# Exercise 2: 2D Sierpinski Triangle

## Goal

Render a 2D fractal using `three.js`. You may choose a fractal from the following list to implement:

- [Sierpinski Carpet](https://en.wikipedia.org/wiki/Sierpi%C5%84ski_carpet)
- [Hilbert Curve](https://en.wikipedia.org/wiki/Hilbert_curve)
- [Moore Curve](https://en.wikipedia.org/wiki/Moore_curve)
- [Gosper Curve](https://en.wikipedia.org/wiki/Gosper_curve)
- [Dragon Curve](https://en.wikipedia.org/wiki/Dragon_curve)

## Instructions

Fill in the missing functions in the starter code provided in `fractal.html`.
You should be able to adjust the recursion depth by using the provided slider on the webpage within the browser, without refreshing the page. You may copy/paste your turtle graphics class from exercise 1 into `fractal.html` to get started.
