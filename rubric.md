## Assumptions for CS Pedagogy Assignment

This homework is designed for students with some programming experience. The assignment would be one exercise within a set for an introductory "Computer Graphics" course taught in Javascript. Students will have already onboarded to three.js, have used similar starter code, git, and familiarized themselves with running javascript code in the browser using basic HTML and `<script></script>` tags. Before this particular assignment, students will have attended a lecture about turtle graphics and a refresher on recursion.

INTRODUCTION TO GIVE IN CLASS:

- This assignment will apply the concepts that we have covered today in lecture including turtle graphics, vector spaces, and recursion. You will be writing your own implementation of a turtle using THREE.js and use it to create fractals.

### Why I am choosing this assignment

This assignment asks students to build a simple turtle-graphics system in THREE.js and use it to generate fractals. The goal is to introduce core 3D programming concepts through a learning-by-doing approach. Students create their own movement and drawing logic to solidify their understanding of coordinate systems, orientation, responding to user input, and recursion. This aligns with research showing that students build stronger mental models when they construct tools and see immediate visual feedback from their code.

This assignment is designed to provide an introduction to 3D programming practices and web-based interaction. The visual output also supports debugging and conceptual understanding, particularly around recursion and spatial reasoning. Finally, the explicit choice to have students first create a common fractal and then make their own is meant to foster intrinsic motivation and learner agency. Turtle graphics and fractals encourage creative expression and experimentation. The artistic and creative aspects of turtle programming also lends itself to allowing students to self-regulate how much of a challenge they are willing to take on.

# Turtle Graphics & Fractals — Project Rubric (1-Week Assignment)

This rubric evaluates your implementation of turtle-graphics-based fractals in **JavaScript + Three.js**, including recursion and scene updates.

---

## **Rubric Overview (100 pts)**

### **1) Turtle Graphics Implementation (45 pts)**

_Write custom turtle-graphics behavior in JavaScript & Three.js_

| Criteria                                             | Points |
| ---------------------------------------------------- | ------ |
| Defines & uses custom turtle functions (move/turn)   | 15     |
| Correct positional & rotational turtle state updates | 15     |
| Turtle drawing logic produces intended line geometry | 15     |

---

### **2) Recursive Fractal Construction (45 pts)**

_Create fractals using turtle graphics + recursion_

| Criteria                                               | Points |
| ------------------------------------------------------ | ------ |
| Correct appeareance for Sierpinski Gasket              | 15     |
| Correct appearance for selected fractal                | 15     |
| Base & recursive cases implemented cleanly & correctly | 15     |

---

### **3) Interactivity & Dynamic Scene Updates (5 pts)**

_Use JS + Three.js to re-render scene based on UI input_

| Criteria                                           | Points |

| Slider changes recursion depth and updates fractal | 5      |
